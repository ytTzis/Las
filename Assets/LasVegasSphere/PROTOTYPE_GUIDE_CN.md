# Las Vegas Sphere 音画实验原型（阶段一至五）

## 已实现范围

- 通用 DSP 事件调度器：声音和视觉共享 `AudioSettings.dspTime`。
- 三个低模事件：近距离拍手、建筑爆炸、飞机飞过头顶。
- 九个观看位置：前/中/后排 × 左/中/右。
- 三个场景始终朝向同一个 `Screen Center View Target`，切换场景不会改变相机朝向规则。
- 所有位置使用相同的声音开始时间。
- 3D 声源方向随观看位置变化；距离衰减保持平坦，多普勒关闭。
- 调试模式和不显示偏移值的参与者模式。
- 球面屏继续使用原来的程序化字符画面。
- 球面屏封闭顶部并水平环绕接近 360°，后方只保留一条位于观众视线外的小接缝。

## 调试模式

- `Q / W / E`：切换拍手、爆炸、飞机。
- `1 / 2 / 3 / 4 / 5`：选择 `-100 / -50 / 0 / +50 / +100 ms`。
- `[` / `]`：依次切换九个观看位置。
- `Space`：播放当前试验。
- `P`：进入参与者模式。

## 参与者模式

- `Enter`：开始随机盲测序列。
- `Space`：当前事件完成后播放下一次。
- `Esc`：退出并返回调试模式。

参与者序列使用拍手、爆炸、飞机三个场景，前中后三个代表位置，以及五档偏移，共 45 次。偏移顺序经过固定随机化，界面不会向参与者显示具体毫秒数。

## 自定义音效

三个场景未指定音频文件时会分别生成临时拍手声、爆炸声和飞机声。后续可以在场景对象的对应 Scenario 组件中给 Event Clip 指定 48 kHz PCM WAV。
